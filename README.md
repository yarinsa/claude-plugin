# yarinsa-practices

Personal Claude Code plugin. Skills I use daily, packaged so they travel across machines and projects.

## Install

```
/plugin marketplace add yarinsa/claude-plugin
/plugin install yarinsa-practices
```

## Skills

| Skill | What it does |
|-------|--------------|
| `playwright-cli` | Drive a real browser from Bash - click, fill, snapshot, eval, trace, mock network, manage storage state. A context-cheap replacement for browser MCP servers. |
